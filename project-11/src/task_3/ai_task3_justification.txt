РАССМОТРЕННЫЕ ВАРИАНТЫ
----------------------

OpenVPN
  + PKI на сертификатах X.509, отзыв через CRL, связка с RADIUS и MFA
  + работает по TCP/443, проходит жёсткие сетевые ограничения
  - ниже производительность, нужен сторонний клиент на каждом устройстве
  - требует отдельного сервера и его сопровождения

WireGuard
  + самый быстрый и простой в настройке, компактная кодовая база
  - не оперирует понятием пользователя, только статические ключи
  - отзыв доступа выполняется ручным удалением ключа
  - нет штатной связки с доменными группами и MFA, только UDP

IPsec IKEv2 на Cisco Secure Firewall
  + функция входит в ПО уже установленного межсетевого экрана
  + клиент встроен в Windows, раздаётся доменной политикой (Always On VPN)
  + аутентификация по сертификатам, проверка прав по группам Active Directory
  + устойчивый роуминг при смене сети
  - привязка к вендору оборудования
  - на нестандартных сетях возможна фильтрация UDP 500 и 4500


ВЫБРАННЫЙ ВАРИАНТ: IPsec IKEv2 на Cisco Secure Firewall 1010

Обоснование:

Этот вариант не требует ни нового оборудования, ни стороннего клиентского
ПО: шлюз FW-EDGE-01 уже стоит на периметре, а клиент IKEv2 встроен в
Windows 11 и раздаётся доменной политикой в режиме Always On VPN. Схема
аутентификации опирается на уже развёрнутые в инфраструктуре роли AD CS и
NPS - сертификат устройства плюс проверка прав по группам Active Directory и
второй фактор, поэтому подключиться может только корпоративная машина
конкретного сотрудника. Наконец, отзыв доступа при увольнении выполняется
штатно - отключением учётной записи в домене и публикацией списка отзыва
сертификатов, тогда как WireGuard со статическими ключами потребовал бы
ручной операции на шлюзе, а OpenVPN - разворачивания и сопровождения
отдельного сервера.
