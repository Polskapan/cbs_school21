НАЗНАЧЕНИЕ

Скрипт обходит указанную сеть и для каждого хоста проверяет, слушает
ли он порт MongoDB и можно ли подключиться к нему и получить список
баз данных БЕЗ пароля. Если это удаётся — экземпляр настроен небезопасно
(доступ без аутентификации), и он попадает в отчёт.

Как это работает:
  1. Быстрая TCP-проверка порта (по умолчанию 27017, 27018, 27019).
  2. Попытка выполнить команду listDatabases без учётных данных.
     - На защищённом сервере команда возвращает ошибку "требуется
       аутентификация" — такой хост НЕ помечается.
     - На открытом сервере команда выполняется — базы выводятся.
Обход хостов выполняется параллельно (пул потоков).


ТРЕБОВАНИЯ

  - Python 3.8+
  - Библиотека pymongo

Установка зависимости:
  pip install pymongo


ЗАПУСК

  # Сканирование всей подсети (CIDR)
  python3 scan.py 192.168.1.0/24

  # Один хост (IP или имя)
  python3 scan.py 192.168.1.10
  python3 scan.py db.example.local

Параметры:
  -p, --ports     порты через запятую (по умолчанию 27017,27018,27019)
  -t, --threads   число потоков (по умолчанию 100)
  --timeout       таймаут соединения в секундах (по умолчанию 2.0)

Пример с параметрами:
  python3 scan.py 10.0.0.0/24 -p 27017,27018 -t 200 --timeout 1.5


ТЕСТИРОВАНИЕ НА ЖИВОЙ БАЗЕ

Проще всего поднять заведомо открытый MongoDB в Docker и отсканировать
localhost.

1) Открытый сервер (без пароля) — ДОЛЖЕН быть найден:

   docker run -d --name mongo-open -p 27017:27017 mongo:7
   python3 scan.py 127.0.0.1
   docker rm -f mongo-open

2) Сервер С паролем — НЕ должен попасть в отчёт (контрольная проверка):

   docker run -d --name mongo-auth -p 27017:27017 \
     -e MONGO_INITDB_ROOT_USERNAME=admin \
     -e MONGO_INITDB_ROOT_PASSWORD=secret mongo:7
   python3 scan.py 127.0.0.1
   docker rm -f mongo-auth


ОЖИДАЕМЫЙ ВЫВОД (при находке)

  [!] ОТКРЫТА без пароля: 127.0.0.1:27017
      Базы данных: admin, config, local, ...

Если открытых экземпляров нет:
  [*] Открытых MongoDB без аутентификации не обнаружено.
