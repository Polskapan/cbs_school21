# Проект 12 — Атака на сети

Краткое описание:
Практики по тестированию на проникновение сетей: сканирование, обнаружение уязвимостей, перехват трафика, эксплойты (в учебных целях и с разрешения).

Рекомендуемая структура:
- tasks/
- tools/ — набор инструментов и скриптов
- reports/ — отчёты по тестам
