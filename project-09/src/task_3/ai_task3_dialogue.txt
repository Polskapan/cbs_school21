ВОПРОС 1
Объясни метод факторизации Ферма для RSA, когда p и q близки.
Напиши псевдокод или Python-функцию, которая находит p и q по N.
Откуда берутся A и B?
 
ОТВЕТ
Метод факторизации Ферма основан на представлении нечётного числа N в виде разности квадратов:
    N = a² - b² = (a + b)(a - b)
Если N = p * q, то:
    p = a - b
    q = a + b

Почему метод хорошо работает, когда p и q близки?
-------------------------------------------------
Пусть:
    q = p + Δ
где Δ — небольшое число.
Тогда:
    a = (p + q) / 2
    b = (q - p) / 2
Если p и q почти равны, то b является небольшим числом. Следовательно, a очень близко к √N.
Поэтому алгоритм начинает поиск с:
    a = ceil(√N)
и постепенно увеличивает a до тех пор, пока выражение
    a² - N
не станет полным квадратом.

Пример
------
Пусть:
    N = 3233 = 53 × 61
1. Находим:
    √3233 ≈ 56.85
Берём:
    a = 57
2. Проверяем:
    57² - 3233 = 16 = 4²
Следовательно:
    b = 4
3. Тогда:
    p = 57 - 4 = 53
    q = 57 + 4 = 61
Факторизация завершена.

Алгоритм
---------
1. Вычислить:
       a = ceil(√N)
2. Вычислить:
       b² = a² - N
3. Если b² является полным квадратом:
       b = √b²
       p = a - b
       q = a + b
       вернуть (p, q)
4. Иначе увеличить a на 1 и повторить проверку.

Псевдокод
----------

FermatFactor(N):
    a ← ceil(sqrt(N))

    while True:
        b2 ← a * a - N

        if b2 является полным квадратом:
            b ← sqrt(b2)
            p ← a - b
            q ← a + b
            return (p, q)

        a ← a + 1

Реализация на Python
--------------------

from math import isqrt

def fermat_factor(N):
    # ceil(sqrt(N))
    a = isqrt(N)
    if a * a < N:
        a += 1

    while True:
        b2 = a * a - N
        b = isqrt(b2)

        if b * b == b2:
            p = a - b
            q = a + b

            if p * q == N:
                return p, q

        a += 1

Пример использования:
N = 3233
p, q = fermat_factor(N)
print(p, q)

Вывод:
53 61

Сложность алгоритма
-------------------

Если обозначить:
    d = |p - q| / 2
то алгоритм выполняет примерно d итераций.
Если p и q отличаются совсем немного, метод работает очень быстро.
Если же множители значительно отличаются по величине, количество итераций становится очень большим, поэтому метод оказывается неэффективным.
Именно поэтому при генерации RSA-ключей простые числа p и q выбирают не только достаточно большими, но и не слишком близкими друг к другу, чтобы факторизация Ферма не могла быть использована для быстрого восстановления множителей.

Если это ваша лабораторная работа, CTF или учебное задание, то ниже приведён универсальный скрипт. Он не зависит от конкретных значений ключа и выполняет все необходимые шаги:

1. Загрузить N, e из crypto.py через importlib
2. Запустить fermat_factor(N) → получить p, q
3. Вычислить φ(N) = (p-1)(q-1)
4. Найти d = e⁻¹ mod φ(N)  через gmpy2.invert()
5. Расшифровать: m = c^d mod N
6. Перевести m в байты и декодировать как UTF-8

from Crypto.Util.number import long_to_bytes, inverse

try:
    import gmpy2

    isqrt = gmpy2.isqrt
    _mpz = gmpy2.mpz
except ImportError:
    from math import isqrt as _pyisqrt

    isqrt = _pyisqrt
    _mpz = int


def fermat_factor(n: int, max_iterations: int = 200_000_000):
    """
    Факторизует n = p * q методом Ферма, предполагая, что p и q близки.
    Возвращает (p, q) с p >= q.

    Примечание: используется gmpy2 (если доступен) для быстрого isqrt на
    больших числах так как math.isqrt из stdlib заметно медленнее при
    переборе в десятки миллионов итераций.
    """
    n = _mpz(n)
    a = isqrt(n)
    if a * a < n:
        a += 1

    for i in range(max_iterations):
        b2 = a * a - n
        b = isqrt(b2)
        if b * b == b2:
            p = int(a + b)
            q = int(a - b)
            return p, q
        a += 1

    raise ValueError("Не удалось разложить N методом Ферма за отведённое число итераций "
                     "(p и q, вероятно, недостаточно близки для этого лимита)")

    print("[*] Запуск атаки Ферма...")

    plaintext_int = pow(ciphertext_int, d, n)

    print(f"[+] FLAG: {flag.decode(errors='replace')}")

    with open("solution.txt", "w") as f:
        f.write(flag.decode(errors="replace"))

ВОПРОС 3
Почему метод Ферма мог не сработать? Какие ещё атаки применимы
для близких p и q?
 
ОТВЕТ
Ферма не сработает, если:
  - p и q слишком далеки → цикл не сходится за разумное время
  - N чётное (нетипично для RSA, но возможно в CTF)
  - Данные в файлах в неожиданном формате (hex/dec/base64)
 
Альтернативные атаки для близких p и q:
  - Ферма с коррекцией: перебирать c в N = a² - c*b², c = 1,2,3...
  - Атака Копперсмита (Coppersmith): работает когда известна
    часть битов p
  - Поиск по базам данных: factordb.com хранит разложения
    многих известных модулей
