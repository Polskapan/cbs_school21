Как использовать:
- Для каждого проекта есть (или будет) папка `project-XX/`.
- Внутри каждой папки можно хранить задания, отчёты, скрипты и образцы конфигураций.
- Я добавил(а) базовые README для большинства проектов с кратким описанием и предложенной структурой.
