# Проект 04 — Исследование пакетов

Краткое описание:
Исследование сетевых пакетов: захват трафика (tcpdump, Wireshark), анализ протоколов, фильтрация, декодирование и реконструкция сессий.

Рекомендуемая структура:
- captures/ — примеры захватов (.pcap)
- analysis/ — разборы и отчёты
- tools/ — скрипты для парсинга
